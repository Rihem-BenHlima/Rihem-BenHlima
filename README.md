## 💡 How I work

- **Evaluate before trusting**: walk-forward validation, baselines (seasonal-naïve, MASE), confusion matrices and error analysis rather than a single headline metric.
- **Use LLMs where they add value**: deterministic code for numbers and retrieval, LLMs for explanation and conversation, always grounded in real data.
- **Keep cost and latency visible**: small task-specific prompts, caching and measured SLAs.
- **Scrape and handle data responsibly**: respect robots.txt and terms of use, keep request delays, document data sources.
